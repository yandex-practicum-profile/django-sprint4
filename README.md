# Блогикум — финальный проект спринта 6

Решение задания «Финальный проект спринта: доработка Блогикум».

## Запуск на этом компьютере

Откройте терминал в папке этого README и выполните:

```bash
venv/bin/python blogicum/manage.py runserver
```

Откройте http://127.0.0.1:8000/ . Остановка сервера — Ctrl+C.
Виртуальное окружение подготовлено, миграции применены, демонстрационная база
заполнена из db.json. Создайте свой аккаунт через кнопку «Регистрация».
Пользователи из фикстуры принадлежат учебным данным; их пароли не нужны.

Для входа в админку создайте собственного администратора:

```bash
venv/bin/python blogicum/manage.py createsuperuser
```

## Установка после переноса в другую папку или на другой компьютер

Нужен Python 3.12. Виртуальное окружение не переносится в архиве.

```bash
python3.12 -m venv venv
source venv/bin/activate
python -m pip install -r requirements.txt
python blogicum/manage.py migrate
python blogicum/manage.py loaddata db.json
python blogicum/manage.py runserver
```

Загрузка фикстуры необязательна. Не загружайте её повторно после редактирования
демонстрационных данных: записи с теми же идентификаторами будут перезаписаны.

## Что реализовано

- Регистрация, вход и выход, изменение и восстановление пароля.
- Общедоступные профили, редактирование только своего имени, фамилии,
  логина и email. Стандартная модель пользователя Django сохранена.
- Создание, редактирование и подтверждаемое удаление своих публикаций.
- Изображения к постам; локальное хранение в blogicum/media/.
- Отложенные и скрытые записи доступны автору, публичные — посетителям.
- Категории и местоположения создаются через административную панель.
- Пагинация по 10 записей на главной, в категории и в профиле.
- Комментарии от старых к новым, счётчики, изменение и удаление только своих.
- Статические страницы через TemplateView; страницы 403 CSRF, 404 и 500.
- Восстановление пароля сохраняет письмо в blogicum/sent_emails/;
  реальная отправка писем не выполняется.
- Bootstrap и изображения интерфейса обслуживаются локально.

HTML-шаблоны перенесены без изменений из указанного в задании репозитория
https://github.com/yandex-praktikum/django-sprint4/ . Основа проекта —
локальное решение предыдущего спринта из ap-django2. Тесты и настройки
проверки из стартового репозитория сохранены в корне проекта.

## Проверки

```bash
venv/bin/python -m pytest
venv/bin/python -m flake8 blogicum
venv/bin/python blogicum/manage.py check
venv/bin/python blogicum/manage.py makemigrations --check --dry-run
```

В открытом наборе Практикума проходят 26 тестов.

При DEBUG=True Django показывает техническую страницу для 404/500.
Для просмотра пользовательских страниц ошибок:

```bash
BLOGICUM_DEBUG=0 venv/bin/python blogicum/manage.py runserver --insecure
```

`--insecure` здесь нужен только для локальной раздачи статики при DEBUG=False.

Проект предназначен для локального обучения. В нём нет настроенного
производственного развёртывания; секретный ключ учебный.
